# Portfolio Cisco Model

Portfolio personale realizzato con React. Il progetto nasce come modello di presentazione professionale per mostrare profilo, competenze, sezioni progetto e contenuti personali in una singola esperienza web.

## Obiettivo

Il repository rappresenta una base portfolio riutilizzabile per:

- presentare competenze frontend;
- organizzare sezioni personali e professionali;
- sperimentare UI component-based con React;
- costruire una vetrina digitale semplice da evolvere.

## Tecnologie

- React
- JavaScript / TypeScript, in base alla versione del progetto
- Componenti riutilizzabili
- Styling modulare

## Stato

Progetto storico / modello portfolio. Utile come riferimento per evoluzioni successive del profilo GitHub e per recuperare componenti o layout.

## Miglioramenti consigliati

- aggiornare copy e contenuti;
- aggiungere screenshot o link demo;
- allineare stile e branding al portfolio principale;
- mantenere solo se serve come archivio storico, altrimenti archiviarlo.
